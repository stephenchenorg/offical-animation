# 客戶｜主題（錄影型）

- 用途：
- 形式：**錄影型**，16:9 橫式 1920×1080。左邊步驟標題，右邊真實系統畫面，下方字幕。
- 錄影：`node record.mjs projects/<名稱>` → `output.mp4`＋`subs.json`；旁白：`npm run voice -- projects/<名稱>`
- 深色版：兩個指令都加 `--theme dark` → `output-dark.mp4`／`output-dark-voice.mp4`

## 分幕

> 每一幕對應 `scenes/` 一個檔，檔名＝下面的標題編號。改這裡就要改那個檔，兩邊要一致。
> 「頁面」欄要跟 scene 檔的 `pages` 一樣：系統哪一頁改版，就靠它找出要重錄的幕。

### 01-總覽｜後台首頁
- 頁面：dashboard
- 畫面：後台首頁，框出「今日訂單」卡片。
- 旁白：登入後台，首頁就看得到今天的訂單數和營收。／數字會即時更新，不用自己去算。
- 字卡：STEP 1 後台首頁

### 02-新增訂單｜新增一筆訂單
- 頁面：orders、dashboard
- 畫面：訂單頁按「新增訂單」→ 填客戶、金額 → 送出 → 回首頁，訂單數＋1。
- 旁白：接到新訂單，按「新增訂單」。／填好客戶和金額，按送出。／回到首頁，今日訂單馬上多一筆。
- 字卡：STEP 2 新增訂單

### 03-報表｜營收報表
- 頁面：report
- 畫面：點「報表」看近 7 天長條圖 → 片尾字卡。
- 旁白：報表頁可以看每天的營收走勢。／以上就是後台的主要功能。
- 字卡：STEP 3 營收報表；片尾「訂單、營收，一個後台全部搞定」
